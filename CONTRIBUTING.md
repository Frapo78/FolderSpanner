# Contributing

FolderSpanner is an MIT-licensed native macOS utility.

1. Open an issue for a bug or feature proposal.
2. Keep the core file system engine separate from the SwiftUI UI.
3. Test changes using temporary directories, never personal collections.
4. Run `swift test` and build the app on macOS before proposing a release.
5. No silent overwrites, implicit recursive moves or automatic execution without a preview and confirmation.

Pull requests should describe safety impact, test coverage and macOS compatibility.
